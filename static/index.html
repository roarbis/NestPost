Video Storage (Cloudflare R2)

Stores generated videos in Cloudflare R2 instead of the database — required for Render hosting. Free tier: 10 GB storage, zero egress fees. Set up at dash.cloudflare.com →

Without R2: videos are stored as blobs in the database (fine for self-hosted, not ideal for Render). With R2: only the URL is stored — much lighter on database storage.

Loading...
Setup steps: Cloudflare dashboard → R2 → Create bucket → Settings → Enable public access → Copy the public URL. Then create an API token with R2 Object Read/Write permissions.

Video Retention

Videos older than the retention period are automatically deleted on app startup to keep storage costs down. The post text, caption, and hashtags are kept — only the video file is removed.
